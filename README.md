# Browser Engine

A simple Java-based starter project for building a browser engine.

## Overview
This repository provides a clean starting point for experimenting with browser-engine concepts such as:
- HTML parsing
- DOM tree creation
- CSS handling
- Rendering basics
- Event handling

## Project Structure
- `Main.java` – application entry point
- `BrowserEngine.java` – core engine bootstrap logic

## Requirements
- Java 17 or newer

## Run the Project
From the project root, run:

```bash
javac Main.java BrowserEngine.java
java Main
```

## Example Output
When you run the project, it will print a startup message for the browser engine.

## Next Steps
You can extend this project by adding:
- a parser for HTML
- a basic rendering pipeline
- CSS support
- navigation and page loading
